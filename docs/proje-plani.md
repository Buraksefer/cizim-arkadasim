# Geliştirme Planı

## İlk prototipin hedefi

Ekranın bir tarafında çizim rehberini göstermek,
diğer tarafında kullanıcının kendi çizimini yapmasını sağlamak.

## Aşama 1: Çizim ekranı

- [ ] React ve TypeScript projesini oluştur
- [ ] Örnek zürafa rehberini ekranın solunda göster
- [ ] Sağ tarafa boş çizim tuvali ekle
- [ ] Kalem, renk ve çizgi kalınlığı seçimini ekle
- [ ] Silgi ve geri alma özelliklerini ekle
- [ ] Çizimi PNG olarak kaydet

## Aşama 2: Adım adım rehber

- [ ] Rehberin adımlarını ayrı ayrı göster
- [ ] Önceki ve sonraki adım düğmelerini ekle
- [ ] Adım değişirken kullanıcının çizimini koru

## Aşama 3: Agent bağlantısı

- [ ] Python ve FastAPI sunucusunu oluştur
- [ ] Konu ve zorluk seviyesi girişini ekle
- [ ] Agent'ın çizim adımlarını planlamasını sağla
- [ ] Görsel üretim aracını bağla
- [ ] Rehberin konuya uygunluğunu ve tutarlılığını kontrol et
- [ ] Düzeltme denemelerine ve maliyete sınır koy

## Aşama 4: Değerlendirme

- [ ] Farklı konularla örnek rehberler oluştur
- [ ] Öğretmen görüşüyle rehberleri değerlendir
- [ ] Hazırlama süresini ve API maliyetini ölç
- [ ] Kullanım sorunlarını düzelt
